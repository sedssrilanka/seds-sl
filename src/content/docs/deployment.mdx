# Deployment Guide

This guide covers the necessary steps to deploy the **SEDS Sri Lanka** platform. Because the site uses **Next.js** and **Keystatic Git-based CMS** with zero external database dependencies, deployment is fast, reliable, and lightweight.

## Prerequisites

Before deploying, ensure you have the following ready:

1. **GitHub Repository:** Access to the `sedssrilanka/seds-sl` repository.
2. **Resend Account:** An active Resend API key for contact forms and email notifications.
3. **Keystatic GitHub App (Optional):** OAuth credentials for online CMS editing at `/keystatic`.

## 1. Environment Variables

You can configure the following environment variables in your hosting provider's dashboard:

```env
# Official Domain
NEXT_PUBLIC_SERVER_URL=https://sedssl.org

# Email (Resend)
RESEND_API_KEY=re_your_api_key
CONTACT_EMAIL=contact@sedssl.org
FROM_EMAIL=noreply@sedssl.org

# Keystatic GitHub Storage Mode
KEYSTATIC_GITHUB_CLIENT_ID=your_client_id
KEYSTATIC_GITHUB_CLIENT_SECRET=your_client_secret
KEYSTATIC_SECRET=your_random_32_character_secret

# Tally Webhook Security (Optional)
TALLY_SIGNING_SECRET=your_tally_signing_secret
```

## 2. Deploying to Cloudflare Workers

The platform runs on **Cloudflare Workers** using `@opennextjs/cloudflare` with Cloudflare Static Assets.

### Option A: Direct Deployment via Wrangler CLI

1. **Login to Cloudflare:**
   ```bash
   bun x wrangler login
   ```

2. **Set Environment Secrets:**
   ```bash
   bun x wrangler secret put RESEND_API_KEY
   bun x wrangler secret put KEYSTATIC_SECRET
   bun x wrangler secret put KEYSTATIC_GITHUB_CLIENT_ID
   bun x wrangler secret put KEYSTATIC_GITHUB_CLIENT_SECRET
   bun x wrangler secret put TALLY_SIGNING_SECRET
   ```

3. **Build and Deploy:**
   ```bash
   bun run deploy
   ```

### Option B: Cloudflare Dashboard (Git Integration)

1. Go to the [Cloudflare Dashboard](https://dash.cloudflare.com/) and navigate to **Workers & Pages** > **Create application** > **Import from Git**.
2. Select your `sedssrilanka/seds-sl` repository.
3. In **Build Settings**:
   - **Framework Preset**: None / OpenNext
   - **Build Command**: `bun run build:worker`
   - **Deploy Command**: `wrangler deploy`
4. In **Environment Variables & Secrets**, add your secrets (`RESEND_API_KEY`, `KEYSTATIC_SECRET`, etc.).
5. Add custom domain `sedssl.org` under Worker **Settings** > **Domains & Routes**.

## 3. GitHub Actions CI/CD Pipeline

The repository includes a built-in CI/CD workflow at `.github/workflows/ci.yml` that automatically:
- Runs TypeScript type checking (`bun run type-check`)
- Checks code formatting and lint rules (`bun run lint`)
- Executes test suites (`bun run test`)
- Builds the Cloudflare Worker bundle (`bun run build:worker`)
- Deploys preview environments for `dev` and production for `main` via `cloudflare/wrangler-action`

Required GitHub Repository Secrets:
- `CLOUDFLARE_API_TOKEN`: Cloudflare API Token with Workers edit permissions.
- `CLOUDFLARE_ACCOUNT_ID`: Your Cloudflare Account ID (found on the Cloudflare Dashboard right sidebar).
