# Welcome to SEDS Sri Lanka Documentation

Welcome to the official documentation for the **SEDS Sri Lanka** website!
This platform serves as the central hub for our divisions, chapters, projects, and merchandise store, powered by **Next.js** and **Keystatic Git-based CMS**.

![SEDS Sri Lanka Homepage](https://placehold.co/800x400/0f172a/ffffff?text=SEDS+Sri+Lanka+Homepage)

## What is this platform?

This website is a full-stack Next.js application utilizing the App Router with zero-database overhead, powered by Keystatic CMS storing content directly in GitHub and Markdoc files in `src/content/`. It uses Tailwind CSS for styling and shadcn/ui for accessible, high-performance components.
