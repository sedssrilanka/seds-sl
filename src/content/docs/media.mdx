# Managing Media Assets

In the Keystatic architecture, media assets and photography are organized in the `public/` directory (e.g. `public/images/projects/`, `public/images/chapters/`, `public/images/products/`).

![Media Admin Panel](https://placehold.co/800x400/0f172a/ffffff?text=Keystatic+CMS:+Media+Assets)

## 1. Adding Images via Keystatic

1. When editing any Chapter, Project, or Product in `/keystatic`, use the image upload fields.
2. Keystatic automatically places uploaded images in the respective `public/images/` subfolder and updates the markdown frontmatter path.

## 2. Best Practices for Images

- **Resize before upload:** Keep images generally `1920x1080` or smaller and under `1MB` for fast loading.
- **WebP & PNG:** High quality `.png` and `.webp` formats are recommended for logos and photography.
- **Naming Conventions:** Use lowercase hyphenated filenames (e.g., `savedino-cover.png`). Avoid spaces or special characters.
